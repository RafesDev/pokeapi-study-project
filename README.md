# Pokédex

A desktop Pokédex application built with Python and the PokéAPI as a learning project.

## Requirements

- Python 3.10+
- requests 2.32.4+

### Standard library (included with Python)

- tkinter
- json
- pathlib
- collections

## Installation

```bash
pip install -r requirements.txt
```

## Running

```bash
python main.py
```
